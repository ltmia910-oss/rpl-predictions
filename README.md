# Таблица прогнозов РПЛ 2026-2027

Многопользовательская программа для отражения прогнозов на матчи Российской Премьер-Лиги.

Программа доступна по ссылке:  
https://ltmia910-oss.github.io/rpl-predictions/

## Возможности:
- авторизация (через учетную запись Google);
- общая база данных — все прогнозы и результаты хранятся в облаке (Firebase);
- обновления в реальном времени — изменения видны всем пользователям сразу;
- шахматная таблица матчей (строки — хозяева, столбцы — гости);
- ввод фактических результатов матчей;
- ввод прогнозов для любого матча;
- рейтинг прогнозистов (очки начисляются за точный счёт и верный исход);
- фильтр по турам;
- тёмная / светлая тема страницы;
- управление списком команд, расписанием и списком прогнозистов через интерфейс.

---

## Архитектура проекта

Браузер (frontend):
- GitHub Pages (отдаёт HTML/CSS/JS); 
- Firebase — база данных + авторизация (всё через интернет-запросы).

## Технологии

| Компонент | Технология |
|-----------|------------|
| Фронтенд | HTML, CSS, JavaScript |
| База данных | Firebase Realtime Database |
| Авторизация | Firebase Authentication (Google) |
| Хостинг | GitHub Pages |
